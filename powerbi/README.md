# Power BI assets

`RetailIQ-Measures.dax` is the governed measure library copied into Power BI
Desktop after importing the marts. Follow
[`docs/powerbi-integration.md`](../docs/powerbi-integration.md) for connection,
relationships, formatting, and reconciliation steps.

A `.pbix`/`.pbit` binary is intentionally not fabricated: its valid creation
requires Power BI Desktop GUI authoring. The database contract and DAX library
are the reproducible, version-controlled deliverables required by Addendum v1.3.
